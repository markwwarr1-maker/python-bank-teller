# Bank Teller Simulation

A Python project that simulates core banking transactions between a bank teller and a customer, including balance inquiries, deposits, withdrawals, and account transfers.

## Features
* **Balance Checks:** Retrieves and displays current balances for both checking and savings accounts.
* **Deposits:** Validates that deposit amounts are greater than zero before updating account balances.
* **Withdrawals:** Prevents overdrafts by verifying sufficient funds before processing a withdrawal.
* **Account Transfers:** Moves funds between checking and savings accounts with built-in balance validation and error handling.

## Technologies & Concepts Used
* **Python 3**
* **Jupyter Notebook**
* **Core Concepts:** Functions, conditional statements (`if`/`elif`/`else`), variable unpacking, and string formatting.

## How to Run
1. Clone this repository to your local machine.
2. Open the `.ipynb` file using Jupyter Notebook, JupyterLab, or VS Code.
3. Run all cells from top to bottom to view the simulated transaction log.
